Barcode Generator Web App

This is a web-based Barcode Generator built using HTML, CSS, and JavaScript. The project allows users to generate barcodes easily and efficiently, with features designed for simple printing and user-friendly interaction.

**Features**

Dynamic Barcode Generation: Users can generate barcodes by entering the desired text or code.

Clean Print View: When the Generate button is clicked, all other elements on the page are temporarily hidden, leaving only the generated barcode visible for easy printing.

Print Button: Directly print the generated barcode from the web page.

Keyboard Support: Pressing the Enter key triggers the generate action, improving user convenience.

**Technologies Used**

HTML, CSS, JavaScript

JsBarcode

**Usage**

Enter your text/code into the input field.

Click the Generate button or press Enter.

The barcode is displayed; all other elements are hidden for printing convenience.

Click the Print button to print the barcode.
